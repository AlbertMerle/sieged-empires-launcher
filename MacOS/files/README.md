# Legacy macOS-only pack overrides (deprecated)

**Normal Mac builds no longer use this folder.** They share `installer/files/manifest.json` with Linux and Windows (universal launcher).

This tree remains for the optional legacy flow only:

| Path | Role (legacy) |
|------|----------------|
| `manifest.json` | Voxy removed, Distant Horizons added — generated by `npm run generate:macos-manifest` |
| `config/` | Optional overlay for Mac-only builds |
| `mods/` | Optional SE override jars for Mac-only builds |

To build with the old Mac-specific pack (not recommended):

```bash
npm run prepare:pack:mac-legacy
# then electron-builder --mac … with MacOS/files/manifest.json wired manually
```

For the universal launcher, ignore this folder and use `npm run dist:mac` or `npm run dist:mac:zip`.
